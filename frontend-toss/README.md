# frontend-toss — 토스 미니앱 `모아`

카드 명세서를 넣으면 카테고리로 나눠 보여주는 앱이다. 평소보다 많이 쓴 것도 알려준다.
그게 전부다 — 챌린지·목표·알림이 없다.

`frontend/`(MOA 본 서비스)와 다른 앱이고 코드를 공유하지 않는다.

## 서버가 없다

분류도 낭비 판정도 휴대폰 안에서 돈다. 표를 번들에 넣었기 때문이다.

```
브랜드 표기표    41 KB   가맹점명에 든 표기 → 브랜드            1,248
분류 사전       52 KB   이미 확인된 가맹점                     522
대조표          43 KB   브랜드 → 소분류 → 중분류, 업종코드 → 중분류
낭비 판정 모델   52 KB   EBM — 특징 11개의 점수표
                ─────
                188 KB   (번들 전체 gzip 119 KB)
```

본 서비스는 이 표들을 서버에 두고 화면이 물어본다. 188 KB 는 들고 다닐 만해서 그냥
넣었다. 그러면 네트워크가 통째로 빠지고, 앱이 늘 빠르고, 어디서나 돈다.

낭비 판정까지 앱에서 도는 것은 **모델이 점수표**이기 때문이다. EBM 은 특징마다 표를 하나씩
들고 찾아서 더하는 것이 전부라 52 KB 에 들어간다. 신경망이었으면 못 넣었다.

**대신 두 단계를 못 가져왔다.** 등록 업종 조회와 모델 추정은 통로가 서버에만 있다.
그 자리는 사용자가 직접 고르는 것이 대신하고, 고른 것은 이 기기가 기억한다.

## 화면 다섯

```
넣기        명세서 CSV 또는 손으로 한 건씩
내역        날짜순. 분류가 틀리면 그 자리에서 고친다
카테고리     도넛 + 목록. 달을 오간다
낭비        평소보다 많이 쓴 것 — 왜 그렇게 봤는지 함께
달마다       소비가 있는 달만 견준다
```

## 만들기

```sh
npm install
npm run dev                     # localhost:5173
npm run build                   # tsc → vite → ait  ⇒ moaa.ait
```

표를 다시 뽑으려면 백엔드 자원에서 만든다.

```sh
python3 ../scripts/build-toss-tables.py                        # 대조표·표기표·모델
python3 ../scripts/build-toss-dictionary.py dict.tsv src/data/dictionary.json
```

엔진만 따로 두드려 본다.

```sh
npx vite build --ssr test/smoke.ts --outDir test-dist && node test-dist/smoke.js
```

## 플랫폼 제약

- **SSR 금지** — CSR 만
- **라이트 모드만** — `prefers-color-scheme` 분기를 두지 않는다
- **확대·축소 비활성화** — `index.html` 의 `user-scalable=no`
- **자체 뒤로가기 금지** — 토스 네비게이션 바가 준다. 그래서 라우터를 안 쓴다
