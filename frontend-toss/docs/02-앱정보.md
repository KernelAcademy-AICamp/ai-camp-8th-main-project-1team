# 02. 콘솔에 넣을 값

앱인토스 콘솔의 **앱 등록 → 기본 정보 / 카테고리 및 노출** 양식에 그대로 옮겨 적을 값이다.
규격은 문서에 적힌 것만 옮겼고, 문서에 없는 항목은 그렇게 표시했다.

## 기본 정보

| 항목 | 값 | 규격 |
|---|---|---|
| **앱 이름** | `모아` | 15자 이내(영문 기준) |
| **appName** | `moa` | `granite.config.ts` 와 같아야 한다. 딥링크가 `intoss://moa` 가 된다 |
| **앱 유형** | 비게임 | — |
| **부제** | `쓴 돈을 모아 보면 보입니다` | 문서에 글자수 미기재 (14자) |
| **상세 설명** | 아래 참조 | 문서에 글자수 미기재 |
| **사용 연령** | 전체 이용가 | — |
| **고객문의 이메일** | *(정해야 함)* | — |
| **카테고리** | *(콘솔 목록 확인 필요)* — 생활/유틸 계열 | — |

`모아` 두 글자는 검색에서 묻힌다. 콘솔이 등록명과 표시명을 가를 수 있으면
등록명은 `모아 - 소비 분석` 으로 두고 홈 화면은 `모아` 로 짧게 둔다.

## 상세 설명

```
소비 내역을 넣으면 카테고리별로 나눠서 보여줘요. 식비, 카페, 교통처럼
어디에 얼마를 썼는지 한눈에 볼 수 있어요.

가맹점 이름만 있어도 무엇에 쓴 돈인지 알아서 찾아줘요. 카드 명세서에는
업종코드가 없어서 '스타벅스 상암DMC점' 같은 이름 하나만 남는데, 모아가
그 이름으로 카테고리를 찾아내요.

분류가 틀렸으면 그 자리에서 바로 고칠 수 있어요. 한 번 고친 가게는
기억해뒀다가 다음부터 자동으로 붙여줘요.

AI가 짐작한 분류에는 'AI 추정'이라고 적어둬요. 사람이 확인한 것과
섞이지 않아서, 어디까지가 확실한지 알 수 있어요.

끝내 알 수 없는 결제는 왜 모르는지까지 알려줘요. 더 찾아보면 정해지는
것과, 간편결제처럼 원래 알 수 없는 것을 갈라서 보여줘요.

평소보다 많이 쓴 소비를 찾아서 알려줘요. 왜 그렇게 봤는지도 함께
보여주니까, 납득이 안 되면 그냥 넘기면 돼요.

달마다 소비가 어떻게 달라졌는지 볼 수 있어요.

챌린지도, 목표도, 알림도 없어요. 소비를 넣으면 분석해서 보여주고
그걸로 끝이에요.
```

마지막 문단이 이 앱을 파는 자리다. 가계부 앱을 지운 사람들은 기능이 적어서가 아니라
잔소리와 미션에 지쳐서 지운다. **없는 것을 먼저 말하면** 그 사람들에게는 그게 설치할
이유가 된다.

## 이미지

| 항목 | 규격 | 상태 |
|---|---|---|
| 앱 로고 | **600 × 600px, PNG, 정사각형** | 올림 — `모아` 워드마크, 브랜드 초록 |
| 스크린샷(세로) | **636 × 1048px, PNG, 최소 3장** | 없음 — 만들어야 함 |
| 스크린샷(가로) | **1504 × 741px, PNG, 최소 1장** | 없음 |
| OG 이미지 | **1200 × 600px (고정)** | 없음 |
| 썸네일 | 1932 × 828px, PNG | 게임만 해당 — 불필요 |

**로고에 걸리는 제약 둘.** 문서가 못박아 두었다.

> 둥근 모서리 사용 불가, 투명 배경 불가

지금 로고가 투명 배경이면 **바탕을 채워 다시 뽑아야 한다.**

## 아직 못 정한 것

- **고객문의 이메일** — 개인 메일을 쓸지 별도로 팔지
- **카테고리** — 콘솔의 선택지를 봐야 안다. 문서에 목록이 없다
- **입력 방식** — 명세서 파일 / 직접 입력 / 둘 다. 이게 정해져야 스크린샷을 찍는다
