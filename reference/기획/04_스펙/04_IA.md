## 1. 구조 원칙

### 1.1 상시 탐색은 3개 탭으로 제한한다

| 탭 | 사용자가 답을 얻는 질문 |
|---|---|
| **홈** | 지금 얼마를 지키는 중인가? |
| **리포트** | 이번 주·이번 달에는 어떻게 지켰는가? |
| **마이** | 내 성역·연결·설정은 어떻게 되어 있나? |

월초 설정과 월말 확정은 매일 찾는 목적지가 아니라 시점에 따라 열리는 인터럽트 플로우다. 별도 탭을 만들지 않는다.

### 1.2 Home의 금액 주 지표는 하나다

- Home에는 `현재 지키는 금액`만 큰 금액으로 표시한다.
- 기준 소비·사용 한도·남은 한도·소진률·목표선을 표시하지 않는다.
- 마이룸 진입 영역에는 연속 방어일과 포인트만 요약하고, 상세는 `RM-01`에서 확인한다.
- 한도 이내 거래는 화면 금액을 바꾸지 않고 알림도 보내지 않는다.
- **`방어율`은 문서·API의 정본 용어이지 화면 라벨이 아니다.** 화면에서는 수치와 맥락만 보여주고 `방어율`이라는 단어를 반드시 노출할 필요는 없다. 표기는 디자인 재량. *(2026-08-03 확정)*

### 1.3 자동 원장과 성장을 분리한다

```text
월중 자동 원장
거래 → 분류 → 합계 한도 비교 → 초과분 차감 → 현재 지키는 금액

월말 성장 원장
최종 지킨 돈 확정 → 누적 지킨 돈 반영 → 레벨(칭호) 갱신

일 단위 마이룸 원장
그날 한도 유지 → 다음 날 아침 소품 1개 지급 → 도감 반영
```

월중 거래가 들어올 때마다 성장시키지 않는다. 월말 확정 전 수정·환불로 값이 바뀔 수 있기 때문이다.

### 1.4 소비 목표는 만들지 않되, 금융상품은 정보성 비교로 제공한다

여행·물건 목표, 목적지, 도착률, 남은 거리, 소비형 보상·상점은 IA에 포함하지 않는다. 지킨 돈의 사용처는 사용자의 자유다.

금융상품은 예외다. 아낀 돈의 보관처(저축)를 다루는 **정보성 비교 추천**은 ③이 담당하며 화면(FP)에 포함한다. 판매·중개·가입 대행은 하지 않고 `가입은 각 사로` 안내하며, 목표 금액·달성 페이스로 제시하지 않는다.

### 1.5 실패를 연기하지 않는다

- 지킴이는 지출에 슬퍼하거나 약해지지 않는다.
- 월말 지킨 돈이 0원이어도 칭호와 마이룸은 그대로 유지된다. **소품은 회수하지 않는다.**
- 내부 `full/partial/missed` 상태는 분석용이며 사용자 메시지는 지킨 금액 중심이다.

## 3. 핵심 사용자 흐름

### 3.1 최초 진입

```text
연결 안내
→ 전송요구·가맹점명 동의
→ 기관 선택·가상 인증
→ 거래 조회
→ AI 소비 분석            [1/4]  (+ 통근/여행 등 불확실 건 확인)
→ 성역 지정               [2/4]
→ 줄일 카테고리 선택       [3/4]
→ 절약 강도 선택 · 지킬 돈 확정  [4/4]
→ 온보딩 완료 · 마이룸 개방
→ Home
```

**성역을 절약 카테고리보다 먼저 받는다.** "안 건드릴 것"을 먼저 확보해야 이후 절약 제안이 통제가 아니라 선택으로 읽힌다.

여행·물건 목표는 입력받지 않는다. 첫 달 목표는 가입일 기준 **일할 계산**으로 축소된다(`01_prd.md` §5.6.2).

### 3.2 월중 자동 지킴

```text
신규 거래 수신
→ 자동 분류
→ 선택 카테고리인가?
   ├─ 아니오: 기록만 저장 · 침묵
   └─ 예: 합계 누적 소비 갱신
          ├─ 합계 사용 한도 이내: Home 금액 유지 · 침묵
          └─ 합계 사용 한도 초과: 초과분만 차감 · 인앱 알림
                                      ├─ 맥락 태그 선택
                                      └─ 오분류 수정
```

### 3.3 월말 성장

```text
월말 원장 마감
→ 최종 지킨 돈 확정
→ RP-02 월말 리포트
→ ③이 확정 금액을 성장 원장에 1회 반영
→ RP-03 월말 성장 연출 (칭호 갱신)
→ 챕터 기록 저장
→ RP-04 다음 달 지킬 것 정하기
```

**마이룸·도감·포인트는 월 경계와 무관하게 이어진다.** 리셋되는 것은 챌린지뿐이다.

### 3.4 월초 재진입

```text
지난달 챕터 요약
→ 이번 달 AI 추천 확인
→ 카테고리·강도 재확정
→ 새 챕터 시작
→ Home
```

누적 칭호와 마이룸은 그대로 유지한다. 2개월차부터는 일할 계수가 1이므로 온전한 한 달 목표가 된다.

#### RP-02 월간 — 성과 정산 + 브릿지 (2026-08-03 확정)

| 순서 | 카드 | 노출 조건 |

| 5 | 소비 패턴 기반 카드 추천 | 항상 |
| 6 | 다음 달 추천 목표 금액 | 항상 |

> **4번의 조건부 노출이 핵심이다.** 브릿지 서사는 "네가 지킨 21만원, 이 통장에 넣으면 이자 X"인데 **지킨 돈이 0이면 이 문장이 성립하지 않는다.** 지킨 돈 없는 달에 상품을 추천하면 맥락 없는 일방향 추천이 되고, 이는 RFP가 지적한 "공급자 중심 일방향 데이터의 한계" 그 자체가 된다.

- 소진률·목표선
- 누적 지킨 돈
- 목적지·남은 거리·보상

누적 지킨 돈을 보려면 마이룸 영역을 눌러 RM-01로 이동한다. 현재 지키는 금액과 장기 누적 금액을 같은 위계에 놓지 않기 위해서다.

### RM-01 · 마이룸

v5의 `CH-02 캐릭터 성장 상세`를 대체한다.

| 항목 | 정의 |
|---|---|
| 목적 | 지켜낸 하루가 쌓인 결과를 눈으로 본다 |
| 표시 | 방과 배치된 소품 · 연속 방어일 · 이번 달 지킴 일수 · 오늘 진행 상태 |
| 표시 | 보유 포인트 · 이번 주 미션 2~3건 · 지킨 날 캘린더 |
| 고지 | `지킨 돈은 내 계좌에 그대로 있어요. 포인트·소품은 꾸미기 전용이라 현금으로 바꿀 수 없어요.` **상시 노출** |
| 액션 | 도감 → RM-02 · 포인트샵 → RM-03 |
| 금지 | 목적지·도착률 · 현금 환급 · 유료 구매 |

**오늘 상태는 자정을 기준으로 확정된다.** `자정까지 오늘을 지키면 내일 아침, 방에 새 소품이 도착해요`로 안내한다. 소품은 즉시 지급하지 않는다 (`01_prd.md` §7.2).

### RM-02 · 도감

| 항목 | 정의 |
|---|---|
| 목적 | 수집 진행과 다음 마일스톤을 보여준다 |
| 표시 | 획득/전체 종수 · 수집률 · 미획득 슬롯 |
| 마일스톤 | 10종 면제권 · 15종 미션 변경권 · 20종 에픽 뽑기 |
| 표시 | 보유 아이템 (예: 면제권 n장) |
| 금지 | 아이템 판매 · 유료 뽑기 |

**면제권은 도감 보상으로만 지급한다.** 포인트샵에서 팔지 않는다 — 챌린지 결과에 영향을 주는 아이템을 판매하면 절약 서비스가 아니게 된다.

### RP-01 · 주간 리포트 — 관찰

| 항목 | 정의 |
|---|---|
| 목적 | 이번 주 어떤 소비가 있었는지 관찰한다 |
| 표시 | 현재 지키는 금액(사실로서만) · 카테고리별 소비 · 시간대·요일 패턴 · 차감·복구 내역 |

| 항목 | 정의 |
|---|---|
| 조건 | 달력 연도 종료 · 챌린지 경계와 맞추지 않는다 |
| 주기 | **달력 연도.** 챌린지를 하지 않은 기간의 소비도 포함한다 |
| 표시 | 연간 소비 사실의 집계 — 횟수·장소 수·시간대 (`영화 32편` · `전시 9회` · `새로 가본 식당 47곳`) |

### FP-03 · 맞춤 카드 비교 (2026-07-28 신설)

소비처별 혜택을 사용자의 실제 소비와 맞춰 **예상 절약액**으로 비교한다.
FP-01(저축)이 자금 흐름 축을 쓰는 것과 달리 **취향 축**을 쓰는 유일한 화면이다.

| 항목 | 정의 |
|---|---|
| 목적 | 이미 하는 소비를 더 싸게 하는 카드를 정보성으로 비교한다 |
| 매칭 근거 | **취향 축** — 카테고리별 소비 × 카드 혜택 (`07_취향분석및추천_Agent_설계.md` §4.4) |
| 표시 | 매칭 상위 3개 · 예상 절약액(연/월) · 매칭 점수 · 추천 사유 |
| 표시 | 사유는 **사용자의 실제 소비 상위 카테고리**를 근거로 (`회원님 지출 상위 2개 카테고리에 겹쳐요`) |
| 표시 | 카탈로그 규모를 밝힌다 (`상품 N개 중 매칭 상위 3개`) |
| 표시 | 정렬 근거를 밝힌다 (`추천은 광고비가 아니라 매칭 점수 순이에요`) |
| 액션 | 각 사 페이지 안내(`가입은 각 사로`) |
| 금지 | 앱 내 발급·신청·중개 · 제휴 링크 |
| 금지 | **소비 증가를 전제한 문장** (`이 카드로 배달 더 시키면 이득`) |
| 금지 | 광고비·제휴 순 정렬 |
| 진입 | 리포트(월간·연간) 내 카드 혜택 발견 카드 |

절약액은 **현재 소비를 그대로 유지했을 때**의 값이다. 늘렸을 때를 가정하지 않는다.
2021년 금융위·금감원이 신용카드 추천도 중개 행위로 판단한 이력이 있어, 저축(FP-01)보다
보수적으로 간다. 근거는 `07_취향분석및추천_Agent_설계.md` §4.4.

## 8. Agent ↔ 화면 책임

| Agent | 주 책임 화면 |
|---|---|
| ① 소비 분석 | MD-01~MD-05 · AN-01~02 · CT-01/01A · NT-03/04 |
| ② 지킴·성장 | CT-02~04 · HM-01/01A/02 · TX-01/02 · NT-01/02/03 · RM-01~03 · MY-02 · SET-06 · ON-03 · RP-03 성장 상태(계산) |
| ③ 취향·추천 | RP-01/02/05/06/**07** · RP-03 성장 서술 · FP-01/02/**03** · 라이프스타일 분석 |
| 공통 | ON-01 · MO-01 · MY-01 · SET · DM-01 |

② 지킴·성장은 금액 로직과 캐릭터·성장 **상태(계산)** 를 소유하고, ③ 취향·추천은 그 상태를 **리포트로 서술**하며 라이프스타일 분석과 금융상품 정보성 추천을 만든다. RP-03은 성장 결과(②)를 ③이 연출·서술한다.
